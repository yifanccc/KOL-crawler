# ntfy 标题格式调整设计

## 状态

已确认并实现，2026-07-13。

## 目标

消除 ntfy 标题与正文的摘要重复。信号通知标题固定为 `平台 | KOL名称 | 时间`，正文继续严格保留中文摘要、标的、方向三行。

## 格式规则

- 平台：`x` 显示为 `X`，`binance_square` 显示为 `Binance Square`；未知平台保留原始值。
- KOL 名称：只使用原帖昵称 `author_name`，不得使用账号名称 `author_handle`；昵称为空时显示 `未知 KOL`。
- 时间：使用原帖 `published_at`，转换到 `Asia/Shanghai`，格式为 `YYYY-MM-DD HH:mm`；缺失时显示 `时间未知`。
- 标题示例：`X | Serenity | 2026-07-13 08:45`、`Binance Square | Btc星辰 | 2026-07-12 12:05`。
- 正文不变：

```text
摘要：<中文摘要>
标的：<标的列表或无>
方向：<方向判断>
```

## 实现范围

- 修改后端通知格式化函数，使其读取 Signal 对应的 RawPost 并生成新标题。
- 修改通知单元测试，精确断言北京时间标题与原有三行正文。
- 更新运维和验收文档中的标题说明。
- 重建 API 容器；已有 NotificationEvent 不重复发送，新格式仅作用于之后产生的通知。

## 验收标准

- 标题不包含摘要、标的或方向。
- 标题只包含昵称，不出现账号 handle。
- 标题精确符合 `平台 | KOL名称 | 北京时间`。
- 正文仍只有摘要、标的、方向三行。
- 后端完整测试通过，API 健康检查通过。
