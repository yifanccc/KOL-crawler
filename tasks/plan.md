# Binance Copy 持仓账本重构计划

## 目标

把私域带单监控拆成三个清晰层级：一行一个 KOL 的账户汇总、一行一个当前持仓的仓位表、一行一次成交操作的流水表；每次操作的 ntfy 通知同时包含操作、该品种操作后持仓和 KOL 汇总。

## 数据口径

- KOL 保证金：Binance Copy 组合详情返回的 `marginBalance`，保留来源时间。
- 持仓总金额：所有有效仓位 `abs(数量 × 标记价格)` 之和。
- 开仓价格：按加仓成交数量计算的加权平均成本；减仓不改变剩余仓位成本。
- 预计盈亏：多头 `(标记价格 - 开仓价格) × 数量`，空头反向计算。
- 持仓保证金与杠杆：仅在 Binance 返回可靠杠杆时计算；缺失时返回空值并显示“数据源未提供”。
- 操作金额：`成交价格 × 成交数量`。

## 实施切片

1. 为加权成本、估值、三层 API 和通知正文添加失败测试。
2. 扩展采集端账本，读取组合保证金与 Binance Futures 标记价格，并上传账户、持仓、流水快照。
3. 扩展后端模型与 API：KOL 汇总、KOL 详情、分页操作流水。
4. 将持仓页改为 KOL 总览表；新增 KOL 详情页，分为“当前持仓”和“操作记录”。
5. 设置页只保留一个“配置订阅”入口；选择 Binance Copy 时只显示组合 ID、10 分钟频率、启用状态与 ntfy，不显示 Prompt。
6. 全量测试、镜像重建和桌面/窄屏浏览器验收。

## 不做

- 不实现 OKX。
- 不用宣传标签猜测精确杠杆。
- 不改生产采集器、不推送、不部署生产。
